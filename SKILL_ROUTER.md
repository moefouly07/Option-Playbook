# Skill Router

## option-playbook

Use:

```text
skills/option-playbook/SKILL.md
```

for:

- teaching the Option Playbook curriculum;
- interpreting CIM-V1 rules;
- chart replay practice;
- preparing or reviewing the backtest;
- option-translation analysis;
- pilot/journal review;
- strategy-governance questions.

## External current-market analysis

The skill may use current Webull, Alpaca, AlphaStocks, and reliable web sources when a live/current example is requested.

Current data is evidence for the current example only. It is not historical validation of CIM-V1.

## Discovery scanner

Use:

```text
scanner/README.md
scanner/SCANNER_V1_1_SPEC.md
```

for Muse scanner runs, scanner-rule questions, acceptance testing, and scanner report review. Scanner output is research only and is not a CIM-V1 signal.

## Future skills

If the repository later contains materially different playbooks, create separate skills rather than expanding one skill indefinitely.
