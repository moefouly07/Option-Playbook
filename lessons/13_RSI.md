# Lesson 13 — RSI

`RSI` مؤشر Momentum محصور عادة بين:

```text
0 and 100
```

## الفكرة

بيقارن قوة الحركات الصاعدة الأخيرة بقوة الحركات الهابطة الأخيرة.

الإعداد الشائع:

```text
RSI14
```

## أشهر سوء فهم

```text
RSI > 70 = Sell
RSI < 30 = Buy
```

دي مش قاعدة موثوقة لوحدها.

السوق القوي ممكن يفضل Overbought فترة.

والسوق الضعيف ممكن يفضل Oversold فترة.

## فايدته

يساعدك تفهم قوة/سرعة الحركة الحالية.

ممكن ندرسه لاحقًا كسؤال:

هل نتائج CIM تختلف لما RSI مرتفع أو منخفض؟

## دوره في V1

```text
RECORDED ONLY
```

ما يمنعش صفقة وما يخلقش صفقة.
