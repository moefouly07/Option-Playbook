# Lesson 00C — Orders and Execution From Zero

## Market Order

طلب تنفيذ بأفضل سعر متاح وقت وصول الأمر للسوق.

الميزة:

```text
سرعة أعلى
```

الخطر:

```text
السعر النهائي غير مضمون
```

## Limit Order

إنت بتحدد الحد الأقصى اللي تقبل تشتري عنده أو الحد الأدنى اللي تقبل تبيع عنده.

الميزة:

```text
تحكم أكبر في السعر
```

الخطر:

```text
ممكن ما يحصلش تنفيذ
```

## Fill

السعر الفعلي اللي اتنفذ عليه الأمر.

ده أهم من:

```text
Mark
Mid
Last
```

لما نراجع صفقة حقيقية.

## Slippage

الفرق بين السعر المرجعي المتوقع وسعر التنفيذ الفعلي.

## Spread friction

لو:

```text
Bid = 1.00
Ask = 1.10
```

واشتريت فورًا على Ask، السوق لازم يتحرك لمصلحتك قبل ما تعوض فرق التنفيذ.

## مشروعنا

في الاختبار من غير Fill حقيقي:

```text
Entry = Ask
Exit = Bid
```

ده افتراض محافظ.

## تدريب بعد الدرس

هنعرض عليك Quotes مختلفة وتحدد:

- أنهي عقد أسهل في التنفيذ.
- ليه Last مش كفاية.
- إمتى Limit Order يكون منطقي.
