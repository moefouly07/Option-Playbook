# Lesson 11 — Pilot Journal

الـ Journal مش دفتر مشاعر.

هو Data Collection.

## قبل الصفقة

سجل:

```text
ORH
ORL
Break time
ATR5
Retest band
Retest bar
Confirmation
Chop state
```

## عند الدخول

سجل:

```text
Underlying entry
Structural stop
R
Target
Option
Bid / Ask
Greeks
IV
Spread
```

## بعد الخروج

سجل:

```text
Exit reason
Underlying R
Option P/L
Option R
MAE
MFE
Slippage
Rule deviation
```

## أهم خانة

```text
Rule deviation
```

لو دخلت صفقة مخالفة، ما نخبيهاش ولا نخلطها بنتائج V1.

تتسجل كـ:

```text
DISCRETIONARY / NON-V1
```

## No Trade days

اليوم اللي مفيهوش صفقة لازم يتسجل.

لأن لو سجلنا الأيام اللي تداولنا فيها بس، مش هنعرف Frequency الحقيقية للنظام.

## هدف Pilot

نتأكد إننا قادرين ننفذ نفس التعريف كل مرة ونقيس Execution Friction.

مش نثبت إننا لقينا ماكينة فلوس.
