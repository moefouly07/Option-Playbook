# Indicators and Context Not Active in CIM-V1

These tools are worth learning and recording, but they do not decide V1 entries.

## Moving averages

- SMA
- EMA
- EMA9
- EMA21
- SMA20

Use: trend/context research.

Risk: adding several averages can duplicate the same information and create false confidence.

## RSI14

Use: measure recent momentum balance.

Important:

```text
Overbought ≠ automatic sell
Oversold   ≠ automatic buy
```

Strong trends can remain overbought or oversold.

## Previous-day levels

- PDH
- PDL

Use: possible liquidity/reference zones.

V1 logs distance but does not filter on them.

## Premarket levels

- Premarket high
- Premarket low

Use: context only in V1.

## Relative volume

Useful for testing whether breakouts with unusual participation behave differently.

Do not add a threshold until it is pre-registered for a new version.

## Macro-event tags

Record major scheduled releases that occur near the strategy window, including common 08:30 ET and 10:00 ET releases and FOMC days.

The event tag is not an active V1 filter.
